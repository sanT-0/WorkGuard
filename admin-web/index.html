Policy Studio
Versions are immutable once published. Editing is limited to drafts; publishing requires submission, approval by a different administrator, and a signed envelope is generated per device at fetch time.
The control plane stores canonical policy content and computes the SHA-256 digest. The Ed25519 signature covers the full device-targeted envelope (spec version, timestamps, target device, digest, and policy), not the stored row alone.

Device Enrollment
Generate a single-use enrollment code. Codes are stored as keyed HMAC-SHA-256 hashes, expire quickly, and cannot be reused.
